# 流程模板调研与适配（2026-10-07）

本轮按既有 20 类场景检索官方机构、框架作者、行业协会和实际产品的公开工作说明。参考资料用于提炼阶段、交付、评审和反馈关系；以下节点与分工是为 Judex 进行的项目协作适配，不是对某份标准的逐字复制或自动执行规则。

## 图与业务规则

- 工作节点使用矩形，人工评审使用菱形；阶段分组和节点类型是表达信息，不授予审批权。
- `advisoryEdges.kind=sequence` 是建议推进，仍要求无环；`kind=feedback` 是人工评审发出的退回说明，必须有说明，并返回能沿正常路径到达该评审的前序节点。
- 实线条件、虚线退回均为人工可读文字，不能执行表达式、自动审批或自动循环任务。前端的工作／提案顺序只读取正常推进连线；硬任务条件和授权沿用原机制。
- 阶段、形状、连线说明不改变业务约束 hash；审阅草稿的 hash 仍覆盖完整节点与连线，元信息变化后不能使用旧审阅发布。
- 注解保存在现有节点与连线 JSON 中，无新增数据库迁移。编辑、发布、版本不可变和来源去重继续沿用原服务。
- 全屏画布支持适应、原始大小、缩放、拖动和横纵方向切换。原始大小按 SVG 本身的尺寸显示，避免复杂图缩放上限不足导致节点不可读。
