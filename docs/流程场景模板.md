# 流程场景模板

项目设置的“协作流程”保留“新建流程”，新增“从模板添加”。用户选择场景、查看流程缩略图或全屏预览、勾选流程并确认添加。每个模板生成一份独立、可编辑的项目草稿，由 owner/manager 明确发布后生效。

## 场景与目录

场景 ID、名称、简介以 `internal/project/catalog/position-presets.json` 为唯一来源。共享 catalog 包为职位和流程提供相同分类；`workflow-presets.json` 只保存流程内容及场景引用。生产从服务端读取目录，显式 demo 使用同一 JSON，生产失败不会回退到 demo。

当前包含 20 类场景、51 个流程模板，其中 26 份轻量流程、25 份完整流程。完整流程按公开行业资料为每个场景补齐阶段、并行工作、人工评审、异常处置和退回路径，完整流程优先展示。资料与适配说明见 [流程模板调研与适配](./流程模板调研与适配.md)。

模板包含稳定 ID、中英文名称、简介、说明、节点名称与职责、建议连线和建议职位。完整模板另有轻量／完整标识、阶段分组、评审形状、条件说明和参考资料。建议职位名称由共享目录派生。目录版本已更新为 2026-10-07.2；旧模板 ID 与已复制项目内容保持独立，完整模板使用新的 ID。

## 选择与预览

- 复用 HeroUI UIDialog、选择框、卡片复选、按钮和统一 Token。文案集中于 `web/src/i18n/workflowPresets.ts`，支持中英文、深浅色和桌面布局。
- 初始要求选择场景，随后双列展示名称、简介、节点数和实际 Mermaid 缩略图。支持多选、全选可添加项、清空选择；切换场景清空选择，取消不写入项目。
- 全屏预览按钮位于卡片复选区域之外，不改变勾选。全屏显示同一份流程、节点职责和建议职位，支持缩放、拖动和适应画布；关闭或返回保留选择，也可从预览中选择模板。
- 共享 Mermaid 渲染器使用 strict 模式，转换内部图 ID 并串行渲染，避免同时绘制缩略图和全屏预览时主题互相覆盖。失败显示提示并可重试。
- 已添加的模板按来源 ID 识别，改名或切换语言不会重复导入。中英文同名的自定义流程也标记为已有，导入不覆盖其内容。
- 提交期间锁定关闭、选择和重复提交。加载失败可重试，提交失败保留选择；成功显示实际新增与跳过数，并定位添加的流程。

## 草稿与发布

流程列表展示草稿与已发布流程。草稿可修改名称、说明、节点名称、职责、阶段、节点类型和后续连线，并增加或删除未受保护的节点。正常推进连线的循环仍被拒绝；带说明的退回连线只能从评审节点返回前序环节，不作为任务循环依赖。空连线保持为空，不制造执行顺序。

有职位绑定、允许职位、委托或硬条件的节点不能在界面直接删除。草稿不出现在职位绑定、工作创建或工作提案的可用流程列表中；发布后再绑定职位。

保存使用编辑时的版本；发布使用审阅时的版本和草稿 hash。未保存修改不能发布，外部版本变化保留本地编辑并提示重新载入，不自动用最新版本覆盖并发修改。保存失败保留输入；已有发布版本不可变。

导入只创建协作草稿，不创建任务、职位、成员或身份，不自动发布，不导入外部对象 ID、委托、硬任务条件或项目审批授权。连线仍表达建议顺序，工作前置条件和正式审批沿用原机制。

## 接口与事务

- `GET /workflow-presets`：带版本的只读目录、共用场景与建议职位名称。需要认证，CLI 沿用 context:read。
- `POST /projects/{projectId}/workflows/import-presets`：请求包含 catalogVersion、scenarioId、workflowIds、locale。仅 owner/manager 浏览器写入，沿用 CSRF 和 Idempotency-Key。
- 服务端校验版本、场景及有效且唯一的选择，在项目锁和一个事务内批量创建，新增、版本、审计和事件完整成功或完整回滚。返回 items 与 skipped。
- 新建和导入共享 insertDefinition。Migration 20 增加可空 preset_id 和项目内来源唯一索引；修改、发布保留来源。
- 普通成员、其他项目用户与归档项目不能导入。并发导入与请求重放不产生重复流程。

- `npm run test:web`：共用场景、独立草稿、无身份副作用、去重、权限、无效选择、循环和版本冲突。
