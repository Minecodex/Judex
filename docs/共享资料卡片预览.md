# 共享资料与讨论文件卡片预览（2026-10-08）

本次根据用户提供的项目共享资料 tab 和讨论右侧资料栏截图，制作根目录 [demo3.html](../demo3.html) 供讨论与视觉评审。它是独立的交互原型，使用示例资料与当前页面内的本地文件；本次不代表正式资料 API、多格式转换服务或删除权限已经实现，也不替换现有正式页面。

## 统一交互

项目共享资料页、计划／任务讨论右侧资料栏、会话内分享的资料，共用一个 `FileCard`。卡片上方按文件格式展示封面、表格缩略图、图片或源码缩略图；下方显示文件名、大小／版本、关联层级、上传人、上传时间、详情与删除按钮。宽资料页为四列，右侧资料栏为两列，消息附件为紧凑卡片，桌面窄边界允许附件换为单列。

点击封面或文件名打开统一弹窗。弹窗中的“文件内容”和“用途与来源”是同一份记录的两种阅读方式，从三个入口打开都保持内容、上传人、版本及关联记录一致。

“这份材料用来做什么”首先显示明确填写的材料用途；来源和关联事实独立显示，包含所属项目、关联计划／任务、上传人、上传时间、上传来源、关联人、关联时间和使用说明。上传时间与后来发送到讨论的时间分开记录。计划／任务关联组织用途，不建立新的文件共享权限边界；沿用 [讨论、材料与事件](./plans/v1/04-讨论材料与事件.md) 的项目共享原则。

## 预览示例和本地文件

| 格式 | 原型中的示例内容 |
| --- | --- |
| PDF | 分页文档、页码与缩放 |
| DOCX | 文档阅读排版与缩放 |
| XLSX | 表格行列、进度状态与图表 |
| PNG | 交互结构图片与缩放 |
| Markdown | 标题、段落、列表与代码块 |
| PPTX | 演示页与翻页 |
| JSON | 格式化源码 |
| ZIP | 包内文件目录 |

示例弹窗明确标记“示例内容预览”。DOCX／XLSX／PPTX 等示例是用于评审阅读方式的页面内容，未实现任意 Office 二进制文件的解析。PDF 示例同样是文档排版演示。

“上传资料”可以选择一个真实本地文件、填写用途并关联当前计划或任务。图片和纯文本在页面中实际读取预览，PDF 使用浏览器自己的 PDF 阅读器；其他本地格式显示暂不支持内容预览并提供原文件下载。文件只保留在当前页面内存中，刷新或重置后移除，不发送到正式服务。原型没有任意上传 HTML 的执行入口；正式网页材料仍须满足既有隔离预览设计。

## 会话分享与删除的候选表现

讨论的“添加共享资料”支持多选已有文件，选择后进入待发送附件区，点击“发送”才生成消息卡片。分享引用同一文件记录，并新增关联人、讨论对象与时间，不重新计算上传人或复制资料。详情里的“发送到讨论”也先加入待发送区，由用户完成发送。

原型允许体验删除所有示例资料。删除前显示确认及被讨论引用的数量；确认后从资料库和右侧资料栏移除，会话保留“资料已删除”的历史引用与详情入口。顶部“重置示例”可恢复示例。**正式产品中的删除权限、已用于审批／交付固定版本的删除处理，仍需在正式实施时按业务契约明确；本原型的表现是待评审候选。**

右侧资料栏可收起、打开、最大化和恢复；讨论草稿保留。项目资料可按文件类型、上传时间排序，按类型筛选，按文件名、上传人或用途搜索。顶部可以切换项目共享资料、计划讨论和任务讨论，支持中文／英文、浅色／深色。

## 来源与复现

原型来源为 `web/material-preview/`，复用正式 HeroUI v3、`Button`、`UIDialog`、头像、表单与全局 design token。页面样式位于 `web/src/styles/material-preview.css`，专用尺寸及格式色位于 `material-preview-tokens.css`；双语文案在 `web/src/i18n/materialPreview.ts` 注册。生成的 `demo3.html` 内嵌全部脚本和样式，可直接离线打开，不依赖 CDN。

```powershell
node web/material-preview/build.mjs
node web/node_modules/typescript/bin/tsc -p web/material-preview/tsconfig.json --noEmit
node node_modules/@playwright/test/cli.js test --config tests/material-preview/config.ts
```

需要浏览器地址时运行 `node tests/material-preview/server.mjs`，访问 `http://127.0.0.1:5197/demo3.html`。测试与截图证据在 `.cache/material-preview-20261008/`。验证范围是独立原型的浏览器交互、桌面布局和本地文件，不计为正式 API／Kubernetes 业务验收。

本轮验证：原型与正式前端类型检查通过，5 项浏览器 E2E 全部通过，覆盖八种示例内容、用途与来源、资料分享及关联追加、删除／取消／历史引用、真实本地文本读取及原文件下载、资料栏与草稿保留、离线打开且无外部资源请求。桌面布局覆盖 1120／1440／1920／3840 宽度、中英文、深浅色及三个入口共 48 组视图，16 组文档弹窗边界检查通过。浅色资料库、讨论卡片、PDF 预览、用途详情与英文深色讨论截图已检查。
