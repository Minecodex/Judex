# V2 测试与切换

按 [工程任务](../plans/v2/TASKS.md)完成 P0～P7，真实证据与原型证据分开。`go test ./...` 保留认证／存储／模型／沙箱基础设施测试；设置 JUDEX_V2_TEST_DSN 才执行独立 PostgreSQL 的账号导入、对等岗位、闭环、预算和恢复测试，不把 skip 算作通过。

`tests/v2/service.mjs` 验证权限、项目群、私聊、版本与分享；cli.mjs 使用原生二进制和真实设备授权；sse.mjs 验证实际 SSE 补收与撤权；agents.mjs 用受控网关验证闭环、并行身份、七工具和统一压缩；formats.mjs 验证全部真实预览；restart.mjs 强制重启自有测试 Pod；real-model.mjs 使用真实 APIMart，单独记证据。

桌面浏览器验证真实注册登录、卡片、直接加成员、三级群、文件右栏、归档后讨论、平台私聊、双语主题、错误与断线。`browser.spec.mjs` 可供 CI 重复执行；本机 CUA 实际操作与截图记录到验收记录。

`collaboration.mjs` 覆盖多人等待、明确回复、同时继续和并行额度；`permissions.mjs` 用实际 CLI、SSE 与沙箱覆盖撤权和指定版本分享。`restart-closures.mjs` 在闭环累计 2 轮时强制删除自有 Server Pod，恢复后核对同一讨论、20 条唯一发言和准确 10 轮暂停。数据库测试另模拟「发言及工具日志已提交、执行检查点尚未保存」，检查恢复不会重复计数；同消息多条闭环超过余量时持久等待下一档结算。

最终切换必须经过临时 Kubernetes 完整部署与同版 ARM64 制品，旧库停止写入后导入认证记录，核对原账号和有效会话，再验证真实 CLI、群聊与模型。验证后清理旧业务数据库、旧对象和旧投影，删除测试 namespace 并恢复本轮暂停的自有副本。全部完成后才能标记 V2 完成。
