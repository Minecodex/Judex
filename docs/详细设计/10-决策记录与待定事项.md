# 当前架构决定

V2 已确定：群聊承载工作，不再维护旧计划任务状态机；职位、工作流和个人提示词指导岗位，不强制安排工作结果。对等岗位共享群知识，通过结构化提及协作；公共摘要服务不协调岗位。

继续 Go/Gin 模块化单体、PostgreSQL、S3、数据库持久任务和 OpenSandbox，不增加消息中间件。三级群权限独立，分享只授予固定内容／版本，私聊属于平台。正式桌面 UI 统一 HeroUI、双语主题和真实数据。

技术恢复与人类继续讨论分别处理；未知副作用核对不等于自动继续。当前额度冻结，新档读取最新设置。认证保留、旧业务清理、协议 2 直接切换，不做旧资源兼容。完整决定见 [V2 合同](../plans/v2/CONTRACTS.md)。本轮验收发现的实现问题记录在发布记录，而不是新增待定产品问题。
