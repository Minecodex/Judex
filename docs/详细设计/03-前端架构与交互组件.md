# 正式前端架构

`web/src/features/workspace` 按项目卡片、列表、聊天、文件阅读、群配置、项目配置、知识和执行日志划分高内聚组件。`components/ProjectArt` 为项目卡片艺术展示，`components/readers` 为 Markdown／PDF 阅读基础。

TanStack Query 管理真实资源，写操作和持久 SSE 事件使查询失效；不存在以模拟状态替代服务端的生产模式。Zustand 只保存偏好和按用户／会话隔离的草稿。上传、消息和控制走带幂等键的公共 API 客户端，错误后保留用户输入。

配置编辑统一通过 configDraft 固定打开／显式载入时的版本，远端失效刷新不更新本地基准；冲突保留编辑，只有明确重载或保存成功才推进基准。消息草稿包含可取消的回复引用。QueryState 统一加载、错误、真实空态和权限失效，文件库和公共知识不能将首次查询错误显示为空内容。

HeroUI v3 为基础组件库，统一包装在 workspace/ui 与通用 ui 中；Tailwind 可用于布局，业务样式统一 `.judex-*`、统一 token。模块 i18n 注册到 `src/i18n/index.ts`，默认中文，英文／深浅主题持久化。

桌面验收和真实浏览器流程见 [界面规范](../界面/README.md)、`tests/v2/browser.spec.mjs`。原型独立位于 `web/v2-preview`，不进入生产路由。

409 回调主动刷新服务端查询，即使未收到 SSE 也能通过显式重新载入或关闭重开恢复；刷新不推进草稿原基准。公共 requester 在成功正文读取及封装校验后才确认幂等键；未知结果保留同一动作，确认后相同内容的下一次提交是新动作。上传保留分片和完成阶段，响应不确定时不取消已提交文件。

ActionMenu 封装 HeroUI Dropdown，统一菜单语义、键盘操作、焦点和关闭行为。ReaderPane 按会话 ID 管理 FileLibrary 与 Reader，缓存文件列表搜索与滚动；返回列表会退出阅读放大，文件卡片重挂载恢复默认最新版。切群重置该容器，防止沿用上一群的搜索或版本更新目标；聊天草稿仍在 Zustand 中按人／会话隔离。认证页的颜色与字号通过基础 token 映射至 workspace token，避免进入工作区前后出现两套配色。

项目设置拆为 settings、settingsMembers、settingsTemplates、settingsCatalog、settingsUI；群设置由 groupSettings 维护，通知／账号／客户端入口由 settingsUtilities 维护。settings 模块文案注册至统一 i18n，所有设置样式在 workspace-settings.css，宽度与侧栏尺寸来自 workspace token。模板库由真实 GET 查询加载，POST 批量导入后统一刷新；显示来源、项目已添加状态与版本历史，不在前端硬编码模板内容。

## 流程图与资料补充（2026-10-20）

统一根字号 90%，token 使用 rem；HeroUI 弹框与控件同步缩小。`WorkflowEditor` 管理图形与自然语言草稿，`WorkflowDiagram` 从结构化节点/边生成严格模式 Mermaid SVG（静态 ID、纯文字标签），支持图形缩放和节点选择；不接受任意 Mermaid 代码或回调。`AccountProfile` 处理昵称/头像编辑、CAS 冲突与重载。

PaneControls 统一各区域标题的收起动作，把隐藏区域的恢复按钮分配给最近的可见区域。无会话的聊天空态也保留标题控件；始终至少显示一栏。导航栏不再放置集中布局菜单，分隔线双击／Home 保留重置入口。

PaneToggle 集中映射三种语义图标，并用 aria-pressed 关联显示状态；显示／隐藏复用同一图标，只改变 token 定义的选中底色和前景。PaneControls 的分配与恢复规则保持一致。
