# 产品边界与身份权限

项目保留成员、职位、参考工作流、描述和运行配置；群与三级独立子群承载协作；平台私聊承载纯人类对话。没有计划、任务、审批、交接和业务完成状态机。

`auth.Principal` 从有效 Web session 或 CLI grant 解析。群资料授权先核验项目有效成员、CLI 项目范围，再核验独立 conversation membership。项目管理员不会自动获得全部群内容。查询与搜索、历史文件、预览、SSE、CLI、模型上下文及沙箱使用相同范围。

群成员可修改本群设置和成员；归档要求项目负责人／管理员已加入目标群。移除项目成员撤销其全部该项目群资格和岗位运行，单群撤销不影响其他群。历史作者与固定版本保留。本人私人提示词和工具执行日志只有本人可读。

授权矩阵、分享与隐藏祖先规则见 [V2 合同](../plans/v2/CONTRACTS.md)。
