# 群工作目录与上下文

每个岗位运行具有独立沙箱和执行日志。只读公共文件投影位于 `/workspace/group/versions/<fileVersionId>/original`；工作产物写到其他 `/workspace` 路径。投影来自当前群公共快照，不包含同项目未入群文件、私人提示词或跨群后续版本。

`read_context` 按知识引用和分页取得原始群资料；压缩摘要只是索引与公共记忆，原始依据持续保留。普通知识更新不唤醒岗位，不重置闭环。下一次模型调用重新组合指导配置和公共快照，并刷新该运行获准文件投影。

`publish_file` 只向本群发布新文件或明确更新本群拥有文件，生成固定版本与公开消息。人类可以显式跨群分享，模型没有该工具。未知工具副作用保留运行目录供岗位本人核对；完成和终止后按归属回收。

预算、压缩、租约和恢复算法见 [V2 合同](../plans/v2/CONTRACTS.md)。
