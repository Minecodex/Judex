# 群聊协作领域

`Project → Group → Conversation` 是协作入口；Group 的 ID 同时是对应 Conversation ID。群以 projectId、parentId、depth 表达固定层级，深度不超过 3；允许多个同级子群。不继承父群成员，不提供跨层移动。

`GroupMembership` 和稳定 `(group,user,position)` 的 `RoleAgent` 分开。成员可有人无岗，也可同人多岗、同岗多人。职位和工作流的内容按修订不可变，个人职位提示词按项目复用。

人发消息或上传文件进入会话；普通消息不触发。结构化岗位提及和本地推送创建或合并当前 Discussion，再登记 Delivery 和 RoleRun。人类提及只通知。所有分支结束后讨论自然收束；明确请求人的分支独立等待。

`dm` 会话按无序双人键唯一，跨项目复用，没有群知识与 AI。领域实现集中于 `internal/collab`，规则见 [完整合同](../plans/v2/CONTRACTS.md)。
