# 后端模块边界

Go/Gin 模块化单体，HTTP handler 只解析合同与身份、调用领域服务并生成 envelope。`internal/app` 组装认证、领域、模型、岗位执行、S3、OpenSandbox 和 PostgreSQL 队列。

| 模块 | 责任 |
| --- | --- |
| identity／platform/auth | 账号、密码、Web session、恢复记录、设备授权、长期主体重新验证 |
| collab | 项目／群／私聊／消息／文件／知识／讨论及统一授权，事务登记通知事件和投递 |
| collab/catalog | 随服务嵌入的双语场景、职位及工作流参考库；不提供执行或协调能力 |
| agent/peer | 对等岗位执行、提示词每次重组、模型预算预留、工具协议日志、租约／检查点／副作用恢复 |
| infrastructure/model | 保留现有模型目录、provider、工具调用流、usage 归一化与适配 |
| infrastructure/opensandbox、groupvolume | 每运行沙箱、只读群快照投影、所有权标记与回收 |
| infrastructure/document | 原件 PDF／图片校验与解析基础 |
| job | PostgreSQL 持久任务、租约、fence、重试与取消 |
| accountimport | 从旧库复制认证记录并核对完整行摘要，不迁移旧业务或 CLI grant |

领域锁按项目／会话、UUID 稳定顺序取得；发送与路由共享会话锁，保证讨论唯一与闭环原子化。外部模型 I/O 不占用数据库长事务；公共压缩有独立数据库租约。数据库业务工具副作用与日志完成在同一事务。

不再加载旧领域 service、协调 Agent 或同步 subagent 委派。详细不变量见 [V2 合同](../plans/v2/CONTRACTS.md)。

模板库读取要求登录，导入只允许人类项目管理者。`collab/presets.go` 校验目录版本与整批选择后，取得项目级事务 advisory lock，复用 SaveTemplate 创建初始修订及配置事件。`preset_id` 和项目内唯一索引记录来源，重复来源或双语同名跳过，失败整批回滚。服务端选择模板内容，前端不提交可冒充内置内容的提示词。

岗位执行保留 2 个并发槽；文件预览使用独立的 1 个 worker。两者按 kind 从同一 PostgreSQL 持久任务表领取，避免长模型调用阻塞文件阅读，不增加消息基础设施。完整工具日志持久保留，过长的已完成工具协议转为公共原文引用，未配对副作用不压缩。

## 流程图与资料补充（2026-10-20）

`workflow` 负责图模型与校验；`collab` 的 workflow.draft 持久任务负责草稿生命周期，复用模型适配与岗位模型并发槽，预览任务独立。模型调用在数据库事务外进行，终态更新校验 fencing token，调用前后检查项目权限；中断返回失败而非盲目重放。账号头像归 identity，规范化小型 PNG 存用户资料，不混入群共享文件。
