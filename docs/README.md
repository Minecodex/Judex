正式工程已生成：`cmd/`、`internal/`、`web/`、`tests/`、`deploy/`。启动见 [根 README](../README.md)，准确能力边界见 [工程骨架与实现状态](./详细设计/13-工程骨架与实现状态.md)。独立 `docs/demo` 已删除，唯一前端工程入口是 `web/`。

**正式设计入口：[详细设计](./详细设计/README.md)。** 已整理 Q056～Q064 的选型与最新注册制度：公司内部部署，员工自由注册和创建项目，账号平级、角色按项目确定；React + HeroUI + Tailwind、Zustand / TanStack Query、Go + Gin、PostgreSQL、SeaweedFS、OpenSandbox 与 Helm。当前为设计基线，尚未代表生产实现完成。

2026-09-27 用户已重新明确以 Chatbox 为主界面，采用面向个人的项目与聊天体验。正式前端 `web/` 已重构为左侧项目/会话、中央讨论/决定、右侧工作/设置，开发服务默认 5173。当前交互范围见 [聊天协作前端重构](./聊天协作前端重构.md)。旧工作室和早期 Chatbox 草图仅保留设计历史，不作为当前运行入口。

最新变化：内网任意用户自由注册；任务图从左到右表达执行先后，按真实前置关系排序，同列工作可并行；父子拆分只表达归属。聊天内的工作提案经列明人员确认后产生计划任务，交接与最终验收保持分离。

最新入口收敛：左侧统一“新建讨论”，头像打开账户菜单；语言、主题、邀请与退出收在菜单中。配置集中到独立设置页，右侧加号仅承载日常工作功能，详见聊天协作前端重构。
