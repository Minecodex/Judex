# 会话、任务协作与分叉

状态：2026-10-07 本轮正式代码、交互预览与隔离验收已完成。运行部署升级作为独立发布步骤；本文不扩大为整套 V1 的所有发行门槛已满足。

## 已确认规则

- 正式与 demo 共用组件树；正式数据来自 API，模拟推送与模拟 AI 结果仅在 demo 显示。
- 左侧按计划组织主讨论与专项讨论，跨计划、未关联、项目级讨论分别呈现。同一会话只有一个身份和计数。
- 保留中央、右侧完整多标签，三栏调整、最大化、账户菜单、独立设置及现有业务功能。
- 计划从讨论形成时默认分叉；原讨论保持。无来源的计划建立空白主讨论，草稿不提前成为正式安排。
- 手动分叉支持当前末尾和任意已提交消息。历史前缀只读共享引用，后续独立追加；多级分叉使用统一解析器。
- 分叉保留原消息身份、作者、材料和来源；不复制报告、审批、票、工具执行或私有上下文。
- 本地上报首先进入任务记录。普通进展和交付遵守既有正式状态门禁；问题和回复是通信记录，不计交付贡献。
- 新记录按流程触发独立任务分析。AI 输出公开结果和讨论建议；有权成员明确选择单独讨论、主讨论继续或已有讨论。
- 普通上报、重复传输、分析及回复均不自动增加会话。正式状态不能由聊天、AI 摘要或建会话动作改变。

## 内部结构变化

PostgreSQL 迁移新增计划主会话、分叉来源与截断点、任务分析、讨论建议及记录引用。共享历史解析器同时服务消息分页与 Agent 上下文；任务分析通过任务级 Agent session 与议题上下文分离。现有 harness、岗位调用、轮次和资源预算继续生效，不增加自由互聊或成员电脑远控。

任务活动统一投影 work_reports 与 task-linked submissions，报告已有 submission 时只显示一份。公开分析只包含白名单字段，个人偏好与私有执行数据不进入共享层。

## 接口

- POST /projects/{projectId}/topics/{topicId}/fork
- GET /projects/{projectId}/tasks/{taskId}/activity
- GET /projects/{projectId}/plans/{planId}/discussion-summary
- GET /projects/{projectId}/discussion-suggestions
- GET/POST /projects/{projectId}/discussion-suggestions/{suggestionId}
- GET /projects/{projectId}/task-analyses/{analysisId}
- POST /projects/{projectId}/task-analyses/{analysisId}/retry

计划返回 mainTopicId，议题返回 parentTopicId、forkAfterSeq 和 sourceRefs，消息返回 inherited、originTopicId 与 taskId。提交的 discussionIntent 为 auto/question/reply；问题和回复使用 purpose=message。CLI 的人确认动作沿用一次浏览器意图，不直接用设备 grant 执行。

## 2026-10-08 项目协同路径收尾

当前入口与旧主会场模式不同：项目协同四标签提供全局事项，计划／任务讨论仅呈现相关会话和上下文。分叉、新建和关联编辑采用一致的多对象选择，固定历史与独立后续记录规则保持。正式报告明确选择任职身份，问题／回复不计入正式交付。交接拒收未验收来源时沿用既有 rework 规则，正式重交与新版来源接收分别处理，接收不替代任务最终验收。详情恢复、草稿、分页与真实验证见 plans/cooperation-ui/CLOSURE-20261008.md。
