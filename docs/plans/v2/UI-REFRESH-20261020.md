# 正式前端视觉与交互改造

2026-10-20。依据用户指定的 [Kylon 聊天工作区](https://app.kylon.io/workspaces/84c2eb741763/chat/rooms/243f18d9c5d8/chat?chat=home) 与用户提供的聊天／阅读截图，改造 `web/src` 的正式产品。

## 参考范围

实际在用户已登录的 Chrome 窗口检查聊天首页、群菜单、群设置弹窗、文件侧栏。只读取和打开／关闭面板，没有发送消息或保存 Kylon 配置。实际网站采用铺满窗口的白色工作区、窄图标导航、整行选中列表、柔和灰色气泡和输入区，菜单收纳次要操作。宣传截图的淡绿色文档阅读容器作为文件阅读参考。

深色模式、项目卡片、岗位配置、闭环控制、公共知识和上传恢复按 Judex 的功能边界延展；不声称它们与 Kylon 未查看页面逐像素一致。保留 Judex 品牌和真实成员身份，不复制 Kylon 人物、商标或网站素材。

## 正式设计基线

- 正文与控件 15px，聊天正文与输入 16px，辅助文字 12–14px，区块标题 18–20px。中文和英文共用字号层级。
- 60px 图标导航；群列表宽度随桌面变化，范围 300–420px；聊天内容最大宽度 920px；文件阅读和资源面板宽度 400–600px。
- 移除外围装饰框和阴影背景，使用细分隔和完整高度；群列表整行选中，三级群保留独立折叠与缩进。
- 主操作使用橄榄色圆角按钮，普通操作使用透明按钮和描边按钮。输入框、文件卡、设置卡与弹窗共用圆角、边框、留白 token。
- 常驻导航为项目、群聊、聊天和通知；底部为本地回流和头像菜单。头像菜单含账号、语言、深浅主题与退出。
- 会话头部保留文件、成员和菜单。搜索按需展开、关闭时清除过滤；公共知识和群设置可由菜单进入。输入区继续保留明确提及和公共知识入口。
- 文件库在右侧打开，聊天仍可操作；支持文件名搜索、清空过滤、打开指定版本、更新、另存和移除。新文件与更新版本分别使用多选／单选上传控件。
- 阅读器保持固定版本、版本记录、下载、分享和全屏阅读。Markdown 已有标题时不再重复渲染文件名标题，统一段落与表格间距。
- 讨论暂停、运行、继续／终止以及上传恢复卡遵循同一套设计；业务状态与额度仍完全来自后端。暂停原因技术码不作为普通正文，运行诊断保留在知识与运行记录中。

## 工程边界与验收

HeroUI v3 是唯一基础 UI 库。统一 ActionMenu 负责键盘、焦点与菜单关闭；没有新增手写菜单事件系统。TanStack Query、Zustand、权限、结构化提及、固定文件版本、幂等和讨论算法保持原有边界。认证页引用相同色板和字体 token；修复会话查询返回 undefined 导致的浏览器错误。

新增共享桌面自动化 `tests/v2/browser-appearance.mjs`，接入正式浏览器套件；更新已有流程以覆盖头像菜单、侧栏文件库和 Enter 发送。原有多用户配置冲突、上传恢复、查询失败和岗位回应流程继续复用。
