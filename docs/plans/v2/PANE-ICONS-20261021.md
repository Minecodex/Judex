# 区域图标与选中状态（2026-10-21）

目标版本：`0.2.0-local.20261021.v2.22`。

会话列表使用双聊天气泡，聊天区使用带文字气泡，文件区使用叠放文件。同一区域的收起与恢复共用同一图标；显示时为浅橄榄底色和强调色图标，隐藏时为灰色图标和透明底色。悬停保留柔和反馈，aria-pressed 同步可见状态。

共享 PaneToggle 映射区域图标，PaneControls 保留最近可见区域恢复、单栏保护、拖动、文件与草稿状态。没有新的业务接口或权限变更。复用 HeroUI Button 与统一 design token，覆盖中文／英文及深色／浅色。

现有真实浏览器导航流程增加三种图标的区别、切换前后图标不变、选中底色区别、键盘恢复，并保留返回、单栏、拖拽和文件版本回归。实际验收以 records 为准。
