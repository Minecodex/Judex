## 固定领域与架构

Go/Gin 模块化单体、PostgreSQL、S3、持久数据库任务队列及 OpenSandbox 保留。项目卡片、配置、职位和参考工作流保留；计划、任务、交接、审批、验收及协调 Agent 已退出正式领域。采用独立成员的三级群、平台人类私聊和每个「群／人／职位」一个稳定岗位身份；成员直接加入，只展示本人加入的群，未加入祖先的名字和 ID 也不展示。归档级联且仍可讨论。

文件内容和消息引用版本不可变；显式更新新增版本，同名上传建立独立文件，分享只授予指定内容／版本。移出库不破坏历史引用。查询、搜索、SSE、CLI、预览、下载、模型上下文和沙箱都核验当前权限；沙箱只读投影本群公共快照至 `/workspace/group`，不挂载项目全文件。

普通网页消息零触发，@人仅通知，结构化 @岗位只投递目标。本地普通推送由服务端解析本人全部岗位，支持只记录；无岗位仍保存并提示。同岗位串行、不同岗位初始并行 2，文件预览独立 1 个 worker。同群最多一段未结束讨论，暂停期间触发合并，不能重置额度。

闭合因果路径共用计数，默认一档 10 轮，可配置 1～100；当前额度冻结，继续读取最新上限增加一档。多条路径同次闭合也不能越过额度，未结算闭环持久等待下一档。任意人类群成员可带意见／空意见继续或终止，终止拒绝迟到结果。人工回应通过明确回复原消息分别解除等待，回复本身仍不唤醒岗位；所有分支结束自然收束。

各岗位共用群知识版本和统一摘要，仅组合提示词、私人执行协议与日志分别保存。每次模型调用重组配置；达到最小有效模型窗口 70% 时压缩至 50%，保留异议、问题、原文依据和近期内容；失败明确暂停，原文持续可回读。私人提示词、隐藏推理和执行控制不进入公共知识。

## 协议与正式客户端

沿用 `/api/v1`，协议能力版本 2；[OpenAPI](../../../api/openapi.yaml)共 74 路径、82 操作。身份由服务端解析；写操作有幂等机制，配置与讨论控制检查原版本；消息、引用、通知、事件与投递同事务。SSE 支持独立持久游标补收和持续撤权校验。

CLI 保留设备登录，支持项目／群、消息与上下文、文件、推送、事件；非空项目范围不泄漏其他项目元数据。message send／push 支持 `--reply-to`，不依赖客户端指定单一岗位。Web 为 HeroUI／统一 token、TanStack Query 与 Zustand，正式包没有模拟回复或示例文件。群／项目／模板／个人提示词共用固定基准草稿，远端刷新不覆盖输入；查询失败与真实为空分开，并有重试及权限失效入口。

完整不变量、授权和算法只在 [CONTRACTS](CONTRACTS.md)维护。
