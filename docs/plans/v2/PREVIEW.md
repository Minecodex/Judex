# V2 桌面交互 Demo

更新：2026-10-19。依据用户提供的 [Kylon](https://kylon.io/) 页面与聊天截图，以及本目录 Q1～Q55 的有效决定制作。当前交付是可以操作的前端 Demo，用于讨论重构后的视觉、信息组织和操作路径。

## 打开与构建

主文件：[demo.html](demo.html)。脚本、样式与示例插画全部内嵌，构建后不依赖网络资源；也可以直接用桌面浏览器打开 HTML。

在仓库根目录运行：

```sh
npm run build:v2
npm run preview:v2
```

访问 [http://127.0.0.1:5199/](http://127.0.0.1:5199/)。默认进入项目卡片列表。直接进入工作区可用 [工作区体验](http://127.0.0.1:5199/?project=judex&group=workspace)。

## 可以实际操作的路径

| 路径 | Demo 行为 |
| --- | --- |
| 项目入口 | 三张风格一致的项目卡片、项目搜索、最近访问筛选、新建示例项目；点击卡片进入工作区 |
| 项目配置 | 修改名称、描述、循环上限；配置职位提示词、个人偏好、参考工作流；添加示例项目成员 |
| 工作区 | 左侧窄导航区分群聊和聊天；群列表搜索、未读筛选与归档列表；聊天占据主要阅读区域 |
| 建群 | 选择项目成员、可选目的、每人一个或多个职位、零个或多个工作流；加入群即可看到本群全部历史 |
| 子群 | 多个同级子群、根群 → 子群 → 第三层；第三层禁止再建下级，子群成员独立选择 |
| 聊天 | 发送文字、文件，保留各群草稿；输入 `@` 或点击提及按钮，明确选择人或具体岗位 AI；支持中文输入法 |
| 文件阅读 | 点击附件展开右侧阅读区、关闭后恢复聊天宽度；支持展开阅读、版本切换、下载；文档、共创表格和代码均有示例 |
| 文件库 | 默认展示可读的最新版本；通过“更新版本”显式发布新版；同名正常上传创建独立文件；移出列表后旧消息仍可读取 |
| 文件分享 | 将选定版本显式分享给本人已加入的目标群；目标群仅展示已分享版本；父子群也需显式分享 |
| AI 触发 | 网页普通消息只记录；@ 人只通知；明确 @ 岗位 AI 才产生对应身份的模拟回复 |
| 本地推送 | 左侧下方“模拟本地推送”可推送文字和示例文件；默认唤醒本人全部本群岗位，也可选择本次只记录 |
| 公共知识 | 查看本群聊天、文件、公开工具结果和示例公共摘要；切换岗位时共同背景不变，职位视角与个人偏好分别组合 |
| 讨论控制 | “岗位 AI 协作”群预置 10 轮暂停卡片；可带意见继续、空意见继续，或终止本次讨论；新 @ 仍可开启模拟回复 |
| 归档 | 示例身份为项目负责人；归档父群时全部子孙群级联进入归档，仍可发言、阅读文件和触发模拟 AI |
| 人类私聊 | 平台用户搜索、发起私聊、文字和文件、右侧预览；跨项目复用同一对话，不产生 AI 回复或群知识 |
| 偏好 | 左下角切换中英文、浅色 / 深色；关于 Demo 中可重置全部示例或快速打开讨论暂停场景 |

“最近访问”在此 Demo 中展示预置的最近项目；在线状态为示例状态。文件上传限 1 MB，文本与常见图片可内嵌查看，其他格式提供下载。

## 视觉与组件边界

- 暖白画布、橄榄绿强调色、浅绿文件阅读外框，深色主题使用对应语义颜色。
- 用头像、留白、轻消息气泡和并排阅读表达协作；设置通过统一弹窗和就近入口打开。
- HeroUI v3 是唯一基础 UI 库。按钮、表单、选择器、头像、卡片、弹窗使用统一封装；图标使用仓库已有的 Lucide。
- 原创示例插画由 CSS / SVG 组成，完全离线；未复制 Kylon 的品牌或人物图片。
- 项目卡片与工作区共享同一套 token、组件、字体和状态约定；所有源码文件低于 2000 行。

源文件：[web/v2-preview](../../../web/v2-preview/)。统一主题与页面样式：[tokens](../../../web/src/styles/v2-preview-tokens.css)、[主布局](../../../web/src/styles/v2-preview.css)、[文件](../../../web/src/styles/v2-preview-files.css)、[弹窗](../../../web/src/styles/v2-preview-dialogs.css)。双语文案：[v2Preview.ts](../../../web/src/i18n/v2Preview.ts)，已注册到前端 i18n 模块清单。

构建入口：[build.mjs](../../../web/v2-preview/build.mjs)。它与已有离线原型采用相同工程方式，输出本目录的单文件 HTML；不替换正式前端路由。

## 本地示例和真实服务的区别

所有修改保存在当前浏览器的 `judex.v2.preview.20261019` 中；刷新可以保留。语言使用 `argus.locale`，Demo 主题使用独立的 `judex.v2.theme`。关于 Demo 中的“重置示例数据”恢复项目、群、消息、文件和演示通知。

AI 回复、工具记录、公共摘要、循环暂停和成员通知均为本地模拟；不会调用模型、运行本地工具、发送外部消息或连接 V1 API。10 轮卡片是可操作的预置场景，不代表已经实现闭环调度、并发计数、压缩、预算或实际取消协议。提示词组合可检查，模拟回复没有真正送入模型。

文件与群受众的选择体现产品规则，仍属于浏览器内演示，不构成服务端授权或安全隔离证明。身份固定为示例负责人林舟，没有实现真实登录、实时多人通信、邀请邮件、持久化服务或 CLI 推送。实际 V2 领域 / API / Agent / CLI 重构及 K8s 全系统验收另行实施。
