# 流程图、账号资料与桌面密度调整

本轮按六项界面反馈实施：设置操作按钮同排、返回按钮命中区域对齐、可编辑流程图和自然语言生成、整体尺寸 90%、项目首页移除重复账号、左下角昵称与头像编辑。

## 实现边界

- 流程图为参考工作流的结构化配置：节点、条件分支、并行关系、反馈回路和说明，随不可变修订保存，进入岗位下一次调用的提示词；不增加业务状态机、审批或自动执行权限。
- 自然语言生成先创建本人项目内的草稿任务，复用 PostgreSQL 持久队列与项目模型。生成不占数据库长事务，与岗位执行共用现有两个模型槽；文件预览 worker 独立。最多两分钟、8192 输出 token；中断不自动重放未知模型调用。结果不自动覆盖，必须先应用草稿、再保存。
- 生成接口受项目管理权限及人类 Web 身份约束，幂等、按人节流；读取仅限作者且再次检查项目权限。岗位 AI 没有这些管理工具。
- 头像属于账号基础资料，不属于任意项目或群文件。客户端裁剪；服务端再次校验 PNG/JPEG 大小和尺寸，去元数据并规范化为 256×256 PNG。仅登录用户读取，同平台用户目录范围。资料修改使用版本校验，密码及会话保持有效。
- schema 14 为工作流修订添加 graph、账号添加小型头像和头像版本、创建持久草稿表。只为内容仍与内置库一致的旧修订恢复原图，不将人工修改内容猜测成图。
- 所有尺寸 token 改为 rem，根字号 90%，HeroUI portal 同步缩小；viewport 高度仍填满窗口。

## 验收范围

布局：职位和工作流按钮同排、返回背景、首页无重复账号、编辑/预览/内置库/成员/账号/文件区，中英文和深浅主题。
功能：图形保存/分支/历史/冲突/图草稿应用，真实模型生成；昵称头像保存后重载、成员与聊天同步、移除头像、错误图片、并发修改；原有服务、CLI、SSE、讨论和浏览器回归。

状态：六项反馈已完成并部署 v2.17。124 项同版场景、25 项 Web 单元及 8 项正常环境冒烟通过；[验收记录](records/FLOW-PROFILE-20261020.md)和[机器记录](records/flow-profile-acceptance-20261020.json)保留实际范围及未重跑项。
