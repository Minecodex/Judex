# 下拉菜单边框与焦点样式

范围：布局、账号、会话、文件操作／版本菜单，以及设置 Select。

问题：原菜单项覆盖使用了不存在的 `.dropdown__item` 类名；全局 `:focus-visible` 的外扩 outline 落在菜单滚动裁切区域中，出现突出或截断的弧形边框。

修复：使用 HeroUI 的 `.menu-item` 和 `.list-box-item`，将弹层与菜单项样式收敛到 `web/src/styles/workspace-menus.css`。统一圆角、内边距、细边框，移除重复覆盖。指针悬停仅用底色；React Aria 键盘可见焦点用内侧细线，保持方向键、Enter、Escape、选择标记及危险操作颜色。选择器触发按钮采用同一规则，普通页面控件的焦点提示保留。

验收：完整桌面 E2E 增加布局菜单、设置选择器和文件版本菜单的鼠标／键盘实际交互与几何边界断言，覆盖深浅主题并保存截图。仅改 CSS，不调整权限、消息、文件版本或 Agent 逻辑。
