# Kylon 参考的正式界面改造与本机升级

日期：2026-10-20。版本：`0.2.0-local.20261020.v2.15`。正式入口：[Judex](http://127.0.0.1:18097/)。本轮已完成正式前端改造、同版回归、本机升级和归属临时资源回收。

## 交付范围

在用户已登录的 Chrome 中查看指定 Kylon 聊天页面、群菜单、群设置和文件侧栏，结合所给图片调整正式 `web/src`。没有修改 Kylon 账号、配置或消息。设计依据见[改造说明](../UI-REFRESH-20261020.md)。

- 全屏白色工作区、60px 图标导航、300–420px 会话列表、完整行选中与细分隔，保留三级独立群。
- 聊天正文／输入 16px，正文控件 15px，辅助文字 12–14px；统一橄榄色按钮、浅灰气泡、输入框和弹窗；深色采用对应中性色。
- 会话头部保留文件、成员和菜单；搜索按需展开，知识和设置通过菜单进入。头像菜单统一账号、语言、主题和退出。
- 文件库从模态框改为右侧面板，可搜索、上传和管理文件，聊天草稿持续保留。文件卡、固定版本阅读器、版本记录和分享使用统一视觉规范。
- 项目卡片、配置、岗位、闭环控制、上传恢复与公共知识沿用同一设计；群、人、岗位和讨论状态仍由真实服务提供。

复用 HeroUI v3、TanStack Query 与 Zustand；新增共享 ActionMenu 和集中样式。没有改变后端执行算法、权限或协议。另修复会话查询返回 undefined 导致的 TanStack Query 浏览器错误。正式制品不含本轮合成示例数据。
