# 分栏、阅读器与确认卡片验收

2026-10-20。本机正式版本为 `0.2.0-local.20261020.v2.18`，协议 2、schema 15，入口 [Judex](http://127.0.0.1:18097/)。

## 交付

- 列表、聊天、阅读区可拖拽，达到阈值收起；按用户和显隐组合记忆宽度。固定导航使用一个轻量「布局」图标菜单，各标题有收起图标，保持至少一栏可见。隐藏不丢草稿、阅读状态与固定版本。
- 确认卡片采用参考图的浅色标题、状态、白色内容和底部浅米色分体操作栏；支持同意、需要修改、编辑意见和多人独立回应。人类也可在输入框请求确认。明确勾选 @ 岗位才触发模型；意见不授予外部动作权限，不绕过暂停额度。
- 阅读器按格式分发：CSV/TSV 真表格、Excel/ODS 工作表、结构树、代码高亮、PDF/Office 分页缩略图、图片缩放、隔离网页、音视频播放、Mermaid 与安全归档条目。
- 服务端、岗位工具、CLI、OpenAPI 与生成类型同步；新增确认回应唯一约束与历史明确回复回填。文件转换保持原件、固定版本和会话授权。

完整格式与容量边界见[实施说明](../WORKSPACE-READERS-20261020.md)。83 个注册扩展名不等于 83 种独立渲染引擎，也不等于全部做过真实样本测试。本轮新增实际文件样本为 39 份，另复跑原文件格式套件。
