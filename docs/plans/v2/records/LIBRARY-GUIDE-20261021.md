# 文件卡片、组合群头像与使用文档验收

版本 `0.2.0-local.20261021.v2.19`，协议 2，schema 15；正常入口 `http://127.0.0.1:18097/`。

## 交付

- 群聊与私聊文件库共用卡片：提交人头像／昵称、准确提交时间、文件大小与版本；默认最新可读版本，右下角切换历史版本，点击文件读取该固定版本。同名文件独立展示；更新／移除使用当前库版本进行并发校验。
- 群列表与聊天标题使用本群前四个有效成员拼接头像，按首次加入时间及 ID 稳定排序。成员移除与头像更新依靠现有 SSE 刷新。
- 左下角使用文档包含安装登录、资料读取、推送与更新、Skill 安装和自然语言示例、讨论与恢复、下载六个章节。命令使用当前项目／群，支持真实剪贴板复制。发行包下载仍与服务器同版。
- 统一 HeroUI 和 design token，支持中文／英文、浅色／深色。群权限、固定版本分享和 Agent 触发规则保持。
