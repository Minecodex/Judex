# 文件卡片、组合头像与使用文档

本轮对应 2026-10-21 三项界面请求，保持 V2 群授权、消息固定版本和讨论触发边界。

## 实施范围

1. 文件库改为 HeroUI 卡片，按版本展示提交人／头像／时间，底部切换授权版本，默认最新；菜单保留新增版本、另存和移除。
2. 群成员按加入时间及 ID 稳定排序，列表与标题使用前四人的组合头像，头像及成员变化随真实 SSE 更新。
3. 左下角改为使用文档，提供六个章节、真实 CLI 命令、Skill 安装与自然语言示例、复制和同版下载。

## 验收

运行 Go 测试／vet、27 项 Web 单元、TypeScript、制品完整性与源码行数检查；带归属 namespace 内执行真实文件版本／成员权限／浏览器及现有完整桌面流程。保存浅色、深色与使用文档截图。验收通过后备份并更新正常服务，保留账号、会话、业务数据和 Secret，清理测试资源。
