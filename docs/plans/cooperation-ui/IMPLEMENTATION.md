## 契约和事实

迁移 00023 增加 Task.mainTopicId 和 Topic.linksVersion。主讨论同事务建立，两个用户／窗口／重试复用，不猜测历史专项。关联整组替换需预期版本且保护主关联；任务所属计划和贡献不改变。

新增任务主讨论命令及交付接收只读投影；会话、计划和本人事项支持服务端范围过滤与分页。计划／会话／待决计数使用同一投影 SQL。列表任务职责批量取得，避免逐节点请求。CLI context 返回 discussionPath，读取与上报不创建主讨论。

审阅时显示服务器固定快照；确认提交同一 reviewId／reviewHash／版本，依据变化不会偷偷重新取最新版本。交接接收只处理对应来源版本；任务和计划分别人工验收。议题当前事实包含任务所属计划，仍使用既有共享历史解析器和独立任务分析上下文。
