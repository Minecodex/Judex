# 职位偏好弹窗与按钮一致性修正

2026-10-08，用户提供三个正式部署截图，指出职位偏好弹窗布局异常、项目协同设置按钮偏小，以及计划路线按钮看起来大小不一致。已修正共享组件与样式，并升级本地运行部署到 Helm revision **15**。

## 原因与修正

- 职位偏好原来把完整页面标题与两列布局直接嵌进弹窗。HeroUI Modal 的 Portal 位于设置页容器之外，设置页的单列适配没有生效；旧 `.judex-work-panel` 的自动外边距又使编辑卡片按内容收缩。现在嵌入模式只使用弹窗标题，编辑卡片占满内容宽度，隐私说明放在下方。布局集中到组件根类与 `position-preferences.css`，删除设置页、聊天面板及旧工作页的重复布局适配。
- 协同页标题区的设置按钮显式为 `sm`（32px），旁边的开启计划按钮为默认 `md`（40px）。新增共享 `ActionGroup` 管理操作区默认尺寸，页面标题区统一标准尺寸；`CardActions` 继续提供紧凑尺寸。项目协同、计划路线和共享页面标题使用同一基础入口。
- 检索发现协同页覆盖了所有按钮的字号、图标尺寸，讨论建议及上报／分叉弹窗又单独覆盖了 outline 按钮的内边距与行高。已移除这些重复密度规则，统一从共享按钮尺寸 Token 读取字号、图标和间距；各语义样式保留相同边框占位。
- 同组按钮的高度、字号和内部对齐一致；宽度随文案长度变化。页面主操作为 40px，卡片操作为 32px，认证主操作为 48px。长文案仍允许在实际空间内换行。

职位选择、本人有效任职范围、按职位保存的独立草稿与修订校验继续使用既有用例。没有修改个人提示词存储、Agent 上下文、权限或业务状态转换。
