## 样式纠正与客户端下载发布（2026-10-07 12:05，Asia/Shanghai）

根据正式部署的反馈，已修正项目搜索图标的垂直对齐、角色标签背景与文字的居中、共享空状态图标和图标按钮的对齐。角色标签原先与旧状态点样式共用类名，文字容器被压缩为 4px；现在使用独立的 `.judex-ui-status`，浏览器断言同时核对文字与背景的中心位置及完整包含关系。交接空列表使用工作面板剩余空间居中显示图标与辅助说明，长说明不再作为大标题。
