## 已确定边界

本轮复用正式 WorkProvider、工作命令、PostgreSQL、事件与冻结审阅。原型模拟状态不作为生产权威来源；新增运行例外属于工作领域，管理员的例外权限不授予任务验收权。任务仍只有一个所属计划，跨计划引用的成果与验收要求不自动解除。普通讨论、记录分析、成员本地工作、交接接收和最终验收继续分别表达。

草稿使用可追溯丢弃标记，默认查询移除，原话题、资料和审计保留。修改草稿时递增实体版本并撤回受影响旧审阅；正式安排修改继续通过现有提案会签。跳过记录包含原任务阶段、操作者、原因、时间和具体约束豁免，不等于验收，不自动启动后继；恢复保留已经发生的工作。规则和目标版本变化必须重新核对，开始与验收阶段分别检查。
