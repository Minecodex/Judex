## 已确定边界

正式 WorkProvider、工作命令、PostgreSQL、事件与冻结审阅保持同一套实现。原型模拟状态不成为生产事实；运行例外属于工作领域，管理员跳过不授予任务验收权。任务只有一个所属计划，跨计划引用的成果与验收要求不自动解除。

草稿按版本修订和可追溯丢弃处理，默认查询移除已丢弃项，原话题、材料及审计保留。修改草稿撤回受影响旧审阅；正式安排修改沿用提案会签。

跳过记录原任务阶段、操作者、原因、时间及具体约束豁免，保留节点，不自动启动后继或视为验收。恢复保留已发生的工作，规则和目标版本变化后重新核对，开始与验收条件分别检查。

任务抽屉和讨论右栏共用概览、原记录、独立 AI 分析及流程参考。全屏保留单独状态，退出恢复来源。桌面、中英文、深浅主题为验收范围；尺寸与控件由[统一规范](../../界面/README.md)定义。

从仓库根目录运行 `node web/task-route-preview/build.mjs` 输出本目录 HTML，再运行 `node tests/task-route-preview/server.mjs`，默认 5396 端口。正式业务完成范围以 STATUS 中的实际镜像和检查为准。
