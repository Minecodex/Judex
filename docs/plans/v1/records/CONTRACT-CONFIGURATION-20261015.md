## 已修复的实际缺口

- **配置列表与写操作查找**：共享分页读取保留筛选与每页数量，完整读取成员、职位、身份、流程、版本和交接后再执行变更；后页错误或重复游标明确失败，不返回半份集合。主目录仍按原有“加载更多”呈现。
- **硬规则目标选择**：复用HeroUI输入、选择和加载更多，支持任务、交接来源、固定资料版本。当前选择独立读取，搜索和翻页不丢引用；可选择历史资料版本，切换事实类型清空旧目标。权限仍由项目API和保存时引用校验决定。
- **分析投影**：任务动态及计划摘要恢复`scopeKind`和结构化`output`，与独立分析读取一致。已有公开事实不会因从另一入口读取而丢字段。
- **邀请投影**：创建、管理和收件人的职位引用由同一批量查询装配；解析链接返回项目与邀请人信息，空职位集合仍是数组。一次性链接仅在创建时返回，列表不泄露token。
- **提案与讨论版本**：草稿保存和修订返回完整提案；修订不再错误要求创建专用的`kind`，并在事务锁内检查`previousReviewId`。旧讨论关联入口检查`expectedVersion`并返回真实Topic；过期请求不改引用。
- **交接提醒**：修正PostgreSQL参数类型推断造成的500，检查交接版本；同一交接一分钟内重复提醒返回429，冷却与登记在同一项目事务中串行执行。成功保留原合同202及实际接收人数。
- **接口定义**：`sourceVersion`为固定版本UUID；交接发送/补交明确要求摘要、下一来源版本及报告引用；重开明确要求验收ID；确认结果、修复传播的独立任务草稿、续开轮数和实际下载MIME与服务端一致。Go/TypeScript/内嵌OpenAPI同步生成。

未改变“本地完成实际工作、平台记录和分析、有权人确认正式决定”的边界，无新增存储迁移。
