## 实现选择与边界

- PostgreSQL 与对象存储保持权威；项目 PVC 是可重建读取缓存，丢失时重新校验准备。prep Job 的短时签名 URL 只用于可信准备容器，业务沙箱没有对象存储凭据。
- 原始一次性 preview URL 兑换后失效；新的版本会话 URL 仍是短时 capability，不可作为永久公开链接。
- 同人兼任多个参与职责时，前端显式选择；只有唯一可操作职责时服务端才允许推断。
- 代批的已实现授权为项目明确 owner。普通 manager 身份不隐含任意代批权；节点级独立委托制度仍需专门授权模型，不能自行扩权。
- 全文设计材料的首次真实调用达到旧的两分钟子调用上限，保留失败事实。随后把子调用限制统一为五分钟、协调者壁钟上限三十分钟；真实设计节选的后续运行已成功：3 个 run、7 次模型调用、18889 token，预留余额为 0；不把前次超时运行算成功。
