# 灵感工作室 2.0：卡片树与交互闭环

历史记录：以下是当时的灵感工作室 2.0 选择与验证结果。2026-09-27 用户重新明确 Chatbox 为主界面，正式前端已改为 [聊天协作工作区](./聊天协作前端重构.md)，任务横向位置表达执行先后；本文不再作为当前 UI 基线。

## 本轮已改

- 计划内改为从左向右展开的卡片树，计划是根节点，直属任务在下一列，子任务继续向右。允许多个子任务，不将“像二叉树”误解为最多只能拆两项。
- 实线表示所属与拆分，虚线箭头表示任务前置 / 交接来源。两种关系共处一图，前置线可开关，不再设置单独的依赖 Tab。没有连前置箭头的同层任务不自动构成串行关系。
- 支持节点展开收起、展开全部、缩放、适应画布、滚动和拖动平移、展开大画布。点击卡片原地查看任务，关闭详情后保留画布位置和缩放。
- 节点右上加号提出子任务草稿，预选上级任务与所属计划；创建时校验父任务同项目、同计划。仍需有权人确认，不能点击加号就产生正式承诺。
- 任务列表改为卡片网格，显示状态、交付内容、责任人、验收人、资料数量、所属计划、子任务数及条件提示；可按本人 / 临时任务、状态、关键词与负责人过滤。
- 计划页顶部显示验收概况、可展开完成条件与“下一步”，全部任务验收后由负责人另行整体验收，不能以资料收齐或树节点展开当成完成。
- “我的今天 → 全部”改为统一待办页，包含交接、工作草稿、任务验收和可整体验收的计划，避免原先只进入交接而遗漏验收。
- 保留已实现的通用项目创建、资料登记、已有成员职位分配，并纳入工作室导航；只清理替代布局，不清空工作记录。

## 闭环检查

| 路径 | 当前结论 | 交互说明 |
| --- | --- | --- |
| 计划草稿 → 负责人确认 | 本地 Demo 已覆盖 | 计划目标、条件、负责人明确；草稿与正式推进状态区分 |
| 任务拆分 → 分配确认 | 已覆盖并补子任务入口 | 父子所属明确；新任务保持草稿，按原授权确认 |
| 本人上报 → 各来源发送 → 接收 | 已覆盖 | 单个来源接收与任务最终验收分别记录 |
| 拒收 → 补交 → 再发送 → 再接收 | 已覆盖 | 要求退回原因；保留其他未受影响来源的决定 |
| 前置未满足 → 后续不能开始 | 已覆盖已确认硬条件 | 卡片提示待满足条件；具体依据在详情查看 |
| 任务验收 → 计划整体验收 | 已覆盖 | 计划完成仍由计划负责人决定；页首提示未完成数量和下一步 |
| 任务重开 → 提醒计划负责人 | 已覆盖 | 原计划验收记录不删除、不自动撤销，由负责人更新正式状态 |
| 多岗位、邀请、换人、个人提示词 | 已覆盖主要演示 | 职位、任职身份和实际操作者区分；管理身份不自动获得任务验收权 |
| 真实本地 AI、CLI、生产并发 | 未接入 | 本轮验证只代表前端原型，不代表生产运行闭环 |

仍需继续改善的交互：

1. **编辑依赖与范围变更**：当前能查看既有前置条件、创建子任务，还不能在图中完整编辑依赖、预览循环或修改影响。下一步应先展示影响，再形成可审阅变更草稿；不建议把拖线直接当作正式工作安排。
2. **大量任务的定位**：当前列表支持搜索、树支持折叠和缩放；可以继续增加树内搜索定位、只看受阻链路、按计划阶段折叠和状态总览。
3. **待办的完整分类**：现已汇总交接和验收，后续再加入多人共同审批、超时提醒、代批覆盖范围、变更版本对比及“为什么轮到我”说明。当前新业务模型尚未整合完整会签计时。
4. **软件场景细节**：Bug 反馈、任意多分支引用、环境 / 发布上报仍需专门的对象视图；保持本地工作与平台收集、提醒、决策的边界。

当前判断：已实现的单人授权、逐来源交接与验收链路在本地 Demo 中可以闭环；完整产品还需要真实工具接入、资料级权限、并发版本控制与上述未实现路径，不能声称全部功能已落地。

## 验证和实现

`TaskTree.tsx` 负责交互，`taskTreeLayout.ts` 负责树布局，`TaskCards.tsx` 为图和列表提供统一卡片。使用共同状态对象，不复制任务进度。画布位置来自父子关系，不通过模型猜测流程箭头。

测试覆盖横向层级、同层不重叠、任意多个兄弟节点、折叠、异常父子环、子任务所属约束、搜索筛选、详情与缩放保持、深色英文、嵌套验收弹窗以及原交接 / 验收回归。旧方案测试随源码清理，当前数字不与此前多方案测试总量混算。

本轮验证：17 项状态 / 布局测试通过，14 项当前工作室浏览器测试通过，构建通过。计划全部任务验收后，首页另展示负责人待整体验收卡；补充测试覆盖这一入口。Mermaid 依赖仍有构建大分块提示，正式交付前需进一步优化。

运行：`npm run dev:background`。验证：`npm test`、`npm run test:e2e`、`npm run build`。截图：`node scripts/capture-studio.mjs`。当前无生产后端，本轮不运行 Kubernetes 部署测试。
