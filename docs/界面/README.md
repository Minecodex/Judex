# 统一界面组件规范

更新：2026-10-09。当前导航见[项目协同](../plans/cooperation-ui/README.md)，任务详情与路线见[Demo4](../plans/demo4/README.md)，共用组件树见[聊天工作区](聊天工作区.md)。完整项目设置保留；原型示例、模拟身份和预览切换不进入正式产品。

## 主题与尺寸

- `web/src/styles/tokens.css` 是正式颜色、字号、间距、圆角、阴影及 HeroUI 语义变量的唯一全局来源；`chat-tokens.css` 只定义布局与由主题派生的别名，不重复覆盖颜色。
- 浅色：背景 `#f7f8f5`，卡片 `#ffffff`，正文 `#23312b`，主色 `#2d6651`；深色：背景 `#171d1a`，卡片 `#1e2722`，正文 `#e4eae3`，主色 `#9fc5aa`。
- 正文 14px，辅助文字 13px，元信息 12px；字体使用统一 UI 字体栈。颜色、尺寸和字体在业务代码中引用 Token，不新增散落的字面值。
- 标准按钮 40px，紧凑按钮 32px，认证表单主按钮/字段 48px；控件圆角 8px，内容卡片 12px，项目卡片 16px。
- 项目／计划列表和普通路线共用 1680px 内容上限；任务抽屉／讨论右栏默认 440px，小桌面为 400／384px，保留合法拖拽尺寸。登录为品牌／表单双栏，表单上限 400px。

## 共享控件

- 所有可见按钮经 `components/ui/Button` 适配 HeroUI；业务 `Btn` 是薄语义包装，不再维护第二套按钮实现。单个操作区的主要动作显式使用 `primary`，辅助动作使用 `outline/secondary`，图标/导航使用 `ghost`，危险操作使用危险语义。
- `Presentation` 提供品牌、头像、页面标题、空状态、偏好控件与 `UIDialog`。业务弹窗通过它渲染，标题和关闭按钮位置一致；普通宽 448px，复杂表单宽 780px，均限制在桌面视口内，超长内容内部滚动。
- 流程模板全屏预览使用同一 UIDialog 的 fullscreen 模式，占满桌面视口，标题与操作区保持可见，画布和节点说明在内容区展示；返回模板保留选择。
- 输入、选择、复选、卡片、提示和状态标签使用 HeroUI 及 `FormControls`；隐藏的原生文件输入仅用于 FileList，入口仍是共享按钮。
- 状态标签统一字号、圆角和间距；已接受、待决定、错误等业务语义保留各自 Token 颜色，不能只靠颜色表达状态。
- 状态标签使用 `.judex-ui-status`，与旧状态点 `.judex-status` 隔离；标签背景必须完整包住文字。搜索图标采用明确的垂直中心定位；空状态和纯图标按钮采用 flex 居中及块级 SVG，验收检查实际图形与文字范围。
- 共享样式在 `presentation.css`，工作区/模块适配在 `workspace-system.css`，认证/项目入口在 `auth.css`。失效的旧工作室项目卡片规则已删除，避免覆盖新卡片内边距。

## 布局与交互

- 标题、说明与主要操作构成一个标题区，搜索/筛选集中到工具栏；详情按人员、条件、资料、记录等业务区块排列。
- 窄工作面板使用单列字段和任务卡片；完整设置页/最大化工作区提供宽内容布局。文件、执行图和多标签仅在自己的区域滚动。
- 三栏分隔线可见宽度 1px，交互命中区 8px；保留拖拽、键盘、取消、重置、最大化和比例记忆。布局键升级为 `judex.chat.layout.v2`，旧宽度不再作为默认；语言、主题、草稿和业务记录不被清理。
- 消息区统一头像、发送人、时间和正文层级；AI 建议有独立卡片背景；消息存在时不重复插入大型欢迎块。Enter 发送，Shift + Enter 换行，中文输入法组合输入不触发发送。
- 收起/最大化工作区与打开设置不会删除会话、丢失草稿或改变业务状态。审批仍依赖服务端冻结依据；交接接收与任务/计划最终验收保持分离。
- 新增入口文案注册在 `src/i18n/portal.ts`；其他业务模块继续使用各自 i18n 文件。默认中文，语言键保留 `argus.locale`，主题键保留 `judex.theme`。

## 真实项目摘要

`GET /projects` 支持 `q`、`ownership=all|owned|joined` 和可选 `include=summary`，保留游标分页，增加匹配项目总数。整页摘要一次批量读取，包含活跃成员数、普通讨论数及最多三位成员的显示信息；不把主会场、交接或已离开的成员计入相应统计。

`GET /me/recent-topics?limit=3` 返回本人可访问的最近讨论，按最后消息时间排序，无消息时按创建时间排序，携带项目和讨论 ID 用于直接导航。归档项目不出现在最近讨论中。

两类读取都检查活跃成员与 CLI 项目范围。没有指定项目范围的 CLI 只能发现自己的项目基础信息，不能读取成员摘要或讨论；其他账户操作仍要求浏览器。原表提供所有事实，无新增存储或数据迁移。项目事件和成功命令使项目列表、最近讨论查询失效；回到入口重新读取，读取失败显示重试，不填充示例数值。

## 本地 AI 下载入口

本地 AI 接入页使用两张下载卡片，分别提供 Windows CLI、macOS CLI 与独立 Skills ZIP。CLI 压缩包分别包含 amd64/arm64 的实际二进制、架构选择启动文件、匹配版本的 Skills 与说明；macOS ZIP 保留执行权限。下载失败显示重试并禁用下载按钮，不使用占位文件。

`scripts/release/client-downloads.mjs` 从当前源码交叉构建，生成版本化 ZIP、大小与 SHA256 清单。正式前端构建的 postbuild 将产物放入 `web/dist/downloads`；服务端沿静态资源通道提供 `/downloads/manifest.json` 和各 ZIP，ZIP 响应明确作为附件，缺失文件返回 404。公开的软件发行文件不包含认证凭据，CLI 登录仍需要浏览器授权。

发布必须给前端构建设置 `JUDEX_RELEASE_VERSION`，并给 Docker 构建传入相同 `VERSION`；Docker 检查发行清单版本，防止网页、客户端与服务端版本错配。`node tests/client-downloads.mjs` 检查四种二进制架构、ZIP 校验值、macOS 权限与本机 CLI/Skill 安装行为；macOS/Windows ARM64 在当前 Windows x64 主机属于已构建和结构验证，不冒充实机运行通过。


## 职位模板选择弹窗

“从模板添加”复用 `UIDialog`：先选择场景，下方用 HeroUI Checkbox 卡片展示名称、职责简介与已添加状态，底部显示选择数量和批量添加操作。复杂弹窗宽度由全局 `--dialog-wide-width` 控制；Header、Body、Footer 的尺寸只在共享样式中定义，已移除聊天样式里的重复 `!important` 覆盖，消除负边距带来的横向溢出。关闭按钮层级明确，提交期间支持锁定关闭与选择。具体目录、数据及权限约定见 [职位场景模板](../功能/职位场景模板.md)。


## 边框与按钮密度

- 浅色分隔/边框 Token `--line` 调整为 `#ccd6cb`，深色为 `#4a5d4e`，让细边框在非整数显示缩放下仍清晰。默认、悬停、选中与键盘焦点分别有独立状态。
- `UICheckbox appearance="card"` 由可点击的 `Checkbox.Content` 绘制一层完整边框、背景及内边距，外层只参与布局。移除旧选项容器与内部标签重复的边框/内边距定义；卡片留白区域也可点击选择。
- 共享按钮以 `sm/md/lg` 分别对应 32/40/48px，正文与内边距随尺寸一起适配。SVG 内部默认上下外边距统一为 0，避免图标撑高按钮；长文案按实际空间换行。
- `CardActions` 提供默认紧凑按钮上下文，职位、成员、提案及交接卡片操作统一使用；页面主操作和认证表单保持标准/大尺寸。整张可点击的任务卡片仍按内容布局。
- `ActionGroup` 管理同一操作区的默认尺寸：页面标题区为 `md`（40px），`CardActions` 为 `sm`（32px），认证主操作为 `lg`（48px）。同一排操作不按主次颜色分别改字号、内边距或行高；按钮宽度随文案变化，高度和内部对齐使用同一尺寸规范。图标尺寸随按钮密度使用共享 Token，主次按钮保留相同边框占位。
- 职位偏好弹窗仅显示一次标题，正文为全宽职位选择、提示词编辑和保存按钮，隐私说明位于下方。布局由 `position-preferences.css` 中组件自身的根类负责，不能依赖设置页或聊天面板祖先；HeroUI Modal 的 Portal 渲染同样适用。避免给编辑卡片使用页面居中自动外边距。
- 桌面验收除尺寸、溢出和交互外，检查可交互边框的命中层级，以及 100/125/150/175/200% 显示比例、深浅色下的四边像素连续性。


## 会话与工作区标签、功能列表反馈

账户与返回项目入口统一由右上角 PortalHeader 承载；项目卡提供邀请与设置。应用内导航保留按项目／用户隔离的标签和未发送草稿。

中间会话与右侧工作区共用一套标签规则：32px 高度、完整单层边框，选中状态使用不透明主色边框。标签列表提供上下内边距，避免水平滚动容器裁切边缘和焦点；保留标签滚动、关闭、多详情、草稿与阅读位置。标签尺寸、选中和悬停规则集中到 `chat-tabs.css`，移除旧圆角/无下边框和重复覆盖。

右侧功能选择列表的默认、悬停、按下与键盘焦点集中在 `workspace-system.css`。悬停使用森林绿浅底、主色边框与箭头反馈；按下使用对应状态色，键盘焦点有明确轮廓。旧悬停规则不再被后续默认规则覆盖。

## 流程前置条件对象选择

硬性前置条件使用共享HeroUI搜索、选择和加载更多：从当前项目选择任务、交接来源或固定资料版本，不要求手填UUID。已选引用独立读取，搜索和翻页不清空；资料可显式选历史版本，切换所需事实类型时清空旧目标。不可读取的既有引用显示核对提示和重试，保存仍由服务端检查项目与引用合法性。配置动作与配置查询共用完整游标读取；后页错误或游标循环不以部分列表执行变更。
