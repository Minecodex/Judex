# 正式 V2 界面规范

视觉基线为 [2026-10-20 正式视觉与交互改造](../plans/v2/UI-REFRESH-20261020.md)，参考用户指定的 Kylon 实际聊天、菜单、群设置与文件侧栏；正式工程在 `web/src/features/workspace`，通过真实 API 和 SSE 工作。HeroUI v3 是唯一基础 UI 库，TanStack Query 保存服务端状态，Zustand 保存按人／会话隔离的草稿与偏好。

登录后的项目卡片进入工作空间：窄导航栏、群／私聊列表、聊天、可开关的并排阅读区。铺满窗口、轻分隔、以 rem token 为基线统一缩小至 90%（基础控件 13.5px、聊天正文 14.4px）、统一留白，避免把业务展示为表单后台。文件卡片代表真实固定版本，不嵌入虚构数据。

统一 token 在 `web/src/styles/workspace-tokens.css`；展示、文件、弹窗和实时状态样式分别位于同目录 `workspace*.css`；菜单和资源侧栏在 `workspace-navigation.css`。认证与公共控件使用统一基础 token。自定义类统一 `.judex-*`，业务组件不散落颜色／间距硬编码。

项目设置采用宽面板／左侧分区、模板库与成员表格；管理界面共用 `workspace-settings.css`，详情见[设置恢复方案](../plans/v2/SETTINGS-RESTORE-20261020.md)。展示更完整的配置内容时仍使用统一 HeroUI 组件和 token。

中文默认，英文可切换，偏好键 `argus.locale`；深浅主题持久化。模块文案分别注册至 `web/src/i18n/index.ts`。验收只覆盖桌面 Web，不承诺移动布局。

真实查询提供加载、空态、失败与重试；写入保留草稿，版本冲突要求刷新；上传显示真实进度，预览显示处理／失败；SSE 断线显示重连，恢复后补收；权限丢失清除阅读内容。无模拟回复、样例文件、重置按钮或虚构在线状态。

见 [聊天工作区](聊天工作区.md)与 [正式验收](../plans/v2/IMPLEMENTATION.md)。

流程图与资料组件共用 `workspace-flow.css`。工作流编辑采用自然语言草稿、图形画布、节点/连线属性与版本历史；图形支持缩放、适应画布及点击节点编辑。所有弹层沿用根字号，设置标题操作保持同排、返回按钮保持对称内边距。账号入口仅在左下角，支持昵称、PNG/JPEG 头像预览/保存/移除。详见[本轮设计](../plans/v2/FLOW-PROFILE-20261020.md)。
