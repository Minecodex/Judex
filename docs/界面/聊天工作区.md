# 当前聊天工作区

更新：2026-10-09。正式与 demo 复用组件树，生产数据来自真实 API；导航与页面规则见[项目协同](../plans/cooperation-ui/README.md)，计划详情与全屏见[Demo4](../plans/demo4/README.md)。旧独立 WorkspaceApp 和早期工作室实现已删除。

## 页面和数据入口

`WorkspaceShell` 承载认证后的项目入口；`ProjectListPage → ProjectHub → PlanRoute / ChatDiscussionView` 表达项目、计划和任务范围。项目协同提供计划、需要我决定、交付与接收、共享资料，项目卡片提供邀请和完整设置。账户位于 `PortalHeader` 右上角。

`WorkProvider` 根据模式接入 API 或 demo 数据，复用业务命令和查询。生产构建不引入 demo Provider、示例身份、模拟推送或固定 AI 结果。API 查询、错误、cursor 分页与 SSE 失效统一处理；查询缺失或失败时显示加载／重试，不回退到示例数据。

讨论只显示当前计划／任务范围的相关会话。计划主讨论沿用持久关系；任务主讨论由明确点击按需建立并复用。上报进展、问题和交付形成原记录及独立分析，不自动建会话。关联、来源跳转与固定位置分叉复用现有用例，不按名称猜对象身份。

## 共用组件与职责

| 组件／层 | 职责 |
| --- | --- |
| `ChatWorkspace`、`SidebarConversations`、`Conversation` | 会话选择、正文、消息提交、来源定位与共享历史 |
| `TaskInspector`、`TaskRecords`、`PlanContext` | 共用详情、原报告、独立 AI 分析、流程参考及正式工作动作 |
| `SettingsScreen` | 项目 AI、成员、任职、流程、模板、私有职位偏好及真实客户端接入 |
| `WorkProvider`、查询与命令用例 | 数据源边界、权限投影、服务端读写与版本冲突 |
| `Button`、`FormControls`、`Presentation` | HeroUI 适配与统一控件、弹窗、标题和空状态 |

同一任务的路线抽屉、交付入口和讨论右栏复用详情组件。右侧标签按对象类型＋ID＋分区去重；外层已选择记录／流程参考时省略内部同名导航。查看文件来源不改变用户明确选择的消息工作范围。

## 草稿、标签与布局

中央会话和右侧工具保留独立可关闭标签。关闭只改变视图，不删除对象、暂停讨论或形成决定；重复打开复用标签。后台更新和侧栏过滤不自动选择另一会话。

界面状态以用户、项目及对象隔离，文字草稿按 topicId 保持；消息工作上下文、导航范围和右侧对象分别表达。临时附件只存在当前页面生命周期内，返回同对象可恢复，刷新或退出后重新选择。公开会话关联多个对象仍只有一份消息历史，正式事实和权限按当前对象查询。

拖拽、键盘微调、取消、重置、最大化和恢复由共享布局处理，收起／最大化和设置返回保留中央草稿。详情保存已加载页数、原文展开、滚动及来源位置；全屏使用独立视图状态，退出恢复来源页面。尺寸与主题来自[统一规范](README.md)。

## 命令与异常

正式命令提交 expectedVersion 和幂等键，以服务器结果为准。过期报告保留原草稿和版本快照，读取最新安排后由人重新核对，不静默替换版本提交。多职责启动或发送交接明确选择职责；任务贡献身份与交接发送职责分开。

异步核对绑定对象和请求代次，晚到响应不覆盖新任务。关联编辑深链接先读话题并固定关联版本，后台刷新与表单快照分离。共享历史只读，定位原消息按需翻页；加载旧历史不跳到末尾。

退出、账号切换和权限撤回清理对应查询与私有视图。消息可展示 pending，审批不提前显示批准；网络、权限、预览失败与版本冲突使用统一双语反馈。
