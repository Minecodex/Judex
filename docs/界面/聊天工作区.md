# V2 聊天工作区

项目卡片是登录入口，项目设置通过统一弹窗维护。群列表只呈现已加入的树节点；隐藏祖先不显示名字或 ID；归档筛选独立，仍可打开并继续讨论。

聊天显示人类作者、岗位身份、时间、CLI 来源、正文和文件卡片。发送普通文字不会调用模型。输入框的提及选择器把人和岗位 AI 分开，选中后保存结构化目标；仅输入 `@名字` 不会路由。每人的草稿按会话隔离，网络或版本失败保留。

消息可选「回复」，输入区显示原作者和原文摘要，支持取消；发出后保留可辨认的引用关系。岗位请求多人回应时分别等待各人的明确回复，普通补充不会解除等待或唤醒 AI；如需岗位继续，回复时同时选择该岗位提及。等待人工且没有正在执行的岗位时，界面显示「等待人类回应」。

结构化人类回应请求显示确认卡片：浅色标题与状态、正文／固定附件、底部分体按钮和编辑意见。指定人可同意、要求修改或仅提意见；普通引用回复也会记入卡片。每人回应一次，结果永久保留。只有显式选择同时 @ 岗位才唤醒；意见不能越过暂停额度、执行外部动作或替代讨论继续／终止。

群设置、项目一般设置、职位／工作流模板及个人提示词使用统一草稿版本基准。SSE 刷新只更新远端版本，不替换编辑内容或基准；出现远端修改时提示，旧草稿保存获得冲突，保留编辑并提供明确的「重新载入最新内容并替换当前编辑」。已移除成员不能由旧表单恢复。

文件卡片打开右栏固定版本，可放大或恢复并排，查看历史、下载、分享。阅读器标题左侧的返回箭头回到当前会话文件列表，保留搜索与滚动位置，并退出放大阅读；文件版本回到卡片默认最新版，消息引用不变。切换会话后重置文件浏览状态。文件库查看本群最新可读版本，来源文件可更新，分享文件可另存；移出列表不删除历史引用。分享弹窗选择本人加入的目标项目和群，只授予指定版本。

列表、聊天和阅读区使用可拖拽分隔线，达到阈值可折叠；各标题使用按区域固定的切换图标：会话列表为双聊天气泡、聊天区为带文字气泡、文件区为叠放文件。显示时是浅橄榄色选中底色，隐藏时恢复按钮为灰色无底色，同一区域不更换图标。按钮通过 aria-pressed 表达显示状态；隐藏栏的恢复图标出现在最近的可见栏标题中，不再使用固定导航的集中「布局」菜单。分隔线双击或按 Home 重置宽度。至少保留一栏；宽度按用户和显隐组合保存。隐藏不卸载草稿或阅读状态，重新打开文件自动显示右栏。

CSV/TSV 使用表格；Excel/OpenDocument 工作簿可切表和切换 PDF 版式；代码提供高亮与搜索；结构数据可切树视图。PDF/Office、图片、隔离 HTML、音视频、Mermaid 和归档条目各使用对应阅读器。所有原件、派生内容和归档条目沿用固定版本授权。具体格式、规模限制与不能运行宏／动画等边界见[阅读器说明](../plans/v2/WORKSPACE-READERS-20261020.md)。

文件库、版本记录、公共摘要、原文历史和运行查询共用加载／失败／真实为空／成功状态组件；失败显示重试，权限失效提供返回项目入口，不能把请求失败显示为「没有文件」或「尚无摘要」。

暂停卡片显示累计闭环与当前额度、原因、可选意见，以及继续／终止。执行信息在群公共知识的运行页显示；岗位本人可打开私人工具日志核对未知结果，保存核对后仍需单独继续。

私聊位于平台聊天导航，跨项目共用同一双方会话，没有 AI 提及和群公共知识。双语、主题、连接状态、空态和错误使用统一组件。自动化入口见 `tests/v2/browser.spec.mjs`；实际证据见 V2 发布记录。

批量附件上传失败后，在输入区上方显示整批确认进度和逐项状态；继续只处理未确认项，重选相同文件集合或子集也复用本批结果。已确认文件不会因后续文件失败而重复上传。结束批次保留服务器已提交内容，下一次选择为明确新上传；成功后同名文件仍可作为独立文件再次上传。

## 当前导航与资源浏览

2026-10-20 改造后，语言、主题、账号与退出统一放在左下头像菜单。会话搜索由右上会话菜单展开，关闭搜索清除过滤；群设置和公共知识也可由该菜单进入。文件库改为右侧面板，打开、搜索、关闭和选中固定版本不丢失消息草稿。新文件支持多选，更新版本只选择一个文件。完整视觉规则见 [正式 UI 改造](../plans/v2/UI-REFRESH-20261020.md)。

## 项目设置与管理

项目设置使用宽面板和左侧分区导航，基本信息、成员、职位、参考工作流、个人提示词分别展示完整内容。基本信息分项目背景和 AI／讨论配置；成员显示头像、姓名、邮箱、权限和操作菜单，移出前说明影响并确认。

职位／工作流有项目卡片列表、搜索、编辑、预览及版本历史。内置库可按场景筛选、多选和批量添加，底部操作始终可达；已导入来源即使被改名也显示「项目已添加」。职位预览显示完整提示词，工作流展示步骤、协作关系和建议职位。导入后的群任职由成员主动配置。

群设置按群信息、成员与任职、参考工作流分区；选中某人后显示其多个岗位选项。个人提示词明确私有边界和提示词组合层次。账号偏好、通知卡片、客户端下载共用相同文字、按钮和边距。实现范围见[设置与内置库恢复](../plans/v2/SETTINGS-RESTORE-20261020.md)。


## 文件卡片、群头像与使用文档（2026-10-21）

- 群聊与私聊文件库使用同一套 HeroUI 文件卡片，展示文件名、类型、大小、该版本提交人的昵称／头像与提交时间，按提交时间倒序排列。同名独立上传保留独立卡片。
- 每个逻辑文件默认展示最新可读版本。卡片右下角的版本按钮按需加载本会话获准读取的版本；选择历史版本后，卡片的提交人、时间、版本标记与打开动作一起切换。重新打开文件库恢复默认最新版。消息中的固定文件引用始终不变。
- 更新、另存和移出文件库收纳在卡片右上角菜单。更新使用当前文件版本校验；历史版本选择不改变写入校验基线；跨群分享只显示获得授权的版本。
- 群列表和聊天标题共用拼接头像：按成员首次加入时间、用户 ID 稳定排序，取本群前四位有效成员。两人并排、三人一大两小、四人四格；无头像使用昵称缩写。成员及个人资料事件自动刷新，不取父群或未加入群的人员。
- 左下角入口为「使用文档」与书本图标。文档分为安装登录、读取资料、推送与文件版本、Skill、讨论与恢复、下载；默认展示安装登录。命令带入当前项目／群 ID，缺失时显示明确占位符。支持复制示例，下载使用同版 manifest 提供的 macOS、Windows 和独立 Skill 包。
- 以上使用统一 token 和 HeroUI，支持中英文及深浅主题；仅桌面端验收。


## 下拉菜单交互（2026-10-21）

动作菜单、文件版本菜单和 Select 弹层共用 `workspace-menus.css`。面板使用统一细边框、圆角和内边距；菜单项保留与面板间距，鼠标悬停只显示柔和底色。键盘焦点使用选项内侧细线，避免全局外扩 outline 被菜单滚动区裁切。方向键、Enter、Escape 和选择标记继续由 HeroUI／React Aria 管理。选择器触发按钮也使用同一内侧焦点规则。浅色与深色均用现有 token，不改变菜单行为。
