# Judex v0.0.1-beta

Judex 首个公开 Beta，基于 V2 群聊协作架构。公开发行版本与内部 V2 实施阶段编号分别管理；本次版本号为 `0.0.1-beta`，Git 标签和容器标签为 `v0.0.1-beta`，API 协议版本保持 2。

## 包含能力

- 项目工作空间、成员和职位配置、私人职位提示词、最多三层且成员独立的群聊、平台私聊与通知。
- 明确 @ 岗位 AI 触发讨论，公共群知识、因果闭环额度、人工继续／终止与未知副作用核对。
- 不可变文件版本、定向分享、并排阅读、表格、Office、图片、音视频和归档预览。
- 20 个场景、118 个职位与 51 个参考工作流；流程图编辑、版本回看与模型草稿。
- 桌面 Web 的中文／英文、深色／浅色主题，以及同版客户端下载和 Skill。
- PostgreSQL 持久队列、执行检查点、OpenSandbox 与群资料只读投影。

## 安装与制品

按 [README 的 Kubernetes 安装步骤](../../README.md#kubernetes-安装)下载同版 Helm Chart、`values-beta.yaml` 和 `models.example.yaml`，创建模型 Secret 后直接用 Helm 安装。

自有容器镜像支持 Linux AMD64 与 ARM64：

| 镜像 | 标签 |
| --- | --- |
| `docker.io/kakj/judex-server` | `v0.0.1-beta` |
| `docker.io/kakj/judex-material-converter` | `v0.0.1-beta` |
| `docker.io/kakj/judex-analysis-sandbox` | `v0.0.1-beta` |

Release 附件包括 Chart、配置示例、六平台 CLI 与 Skill、两架构 Linux Server、Web、OpenAPI、许可证、来源清单及 SHA-256 校验和。`images.json` 单独记录 Docker Hub 镜像索引摘要，配套 `images.json.sha256`。

PostgreSQL、SeaweedFS、OpenSandbox Controller／Server／execd／egress 由上游镜像提供，版本见 Chart 与 [上游记录](../../deploy/helm/UPSTREAM.md)。已有兼容 OpenSandbox Controller 的集群须禁用本 Chart 的 Controller 子 Chart。

首次安装的 Controller 固定为 `release-1.1.1`，与本机已验证的共享 Controller 及发行 CI 一致；不使用浮动的 `latest`。执行时限测试增加准备余量与 provider 已调用断言，避免共享 CI 的准备耗时被误判为执行中取消。

## 验证范围

本次发行使用同一提交构建 Server、Web、CLI、Skill 和 Chart，并核对包版本与校验和。实际执行结果、镜像摘要、临时 Kubernetes 资源清理记录随发布验收更新；历史本机阶段测试不计为本次重新执行。真实模型能力取决于部署者配置，本次确定性回归使用受控模型网关。

当前版本仍在开发阶段，后续版本可能调整数据结构和协议。默认内置数据库与对象存储适合初次部署；容量、高可用、备份策略和集群网络隔离需按实际环境配置。
