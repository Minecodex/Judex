# Local work return

Choose a joined group, review its purpose, members, current conversation and public references. Report only actual local actions, relevant evidence and unresolved points. Attach the exact files the user selected. Publishing content does not establish approval or acceptance.

A normal local push wakes the sender's currently assigned roles; the server resolves every role. `--record-only` saves without an AI trigger. A user with no assigned role can still save content. Do not use model outputs as proof that a local command or test ran.

Repeated sends after network loss must keep the persisted idempotency receipt. Explicit file updates require the expected file configuration version. Do not merge independently uploaded files by filename.
